What's inside

Two modules, one project

The presentation describes the storage dashboard; the report documents the cognitive game platform. CloudBox ships both in a single, consistent interface.

☁️

Cloud Storage Dashboard

The CloudBox storage prototype from the presentation: upload, search, manage and watch your 100 MB quota in real time.

  • Select or drag in multiple files at once
  • Live quota calculation with a warning state
  • Filename search and one-click delete
  • Metadata kept in localStorage between visits
Open storage dashboard →
🧠

Cognitive Games Arena

Twelve short browser games across two tracks, with instant feedback and a performance dashboard — the project described in the report.

  • Six Cognitive Aptitude games
  • Six Game-Based Assessment games
  • Scoring, performance index and saved bests
  • Keyboard-friendly, fully client-side
Enter the arena →
Built for the demo

Small project, complete workflow

Every feature maps to a concept from the Cloud Computing syllabus: quota management, client-side storage, and a frontend deployed as static cloud hosting.

🛡️

Quota guard

Every upload is checked against the 100 MB limit before it is accepted.

🔍

Search & manage

Filter by filename, remove entries, or reset the demo with one click.

📈

Live analytics

File count, used space, free space and progress update instantly.

📱

Responsive

The dashboard and games adapt from wide desktop screens down to phones.

Technology stack

Dependency-free and easy to grade

HTML5 structure CSS3 layout JavaScript ES6 localStorage persistence GitHub Pages hosting Vercel (report reference)

The submitted report describes a React 19 + TypeScript build deployed on Vercel. This repository re-implements the experience as a dependency-free static site so it can be opened, reviewed and hosted without a build step.
