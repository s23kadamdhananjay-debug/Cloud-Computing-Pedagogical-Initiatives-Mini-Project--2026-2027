📝 Abstract

CloudBox is a browser-based application that demonstrates two sides of a modern cloud project. The storage module lets a user select files, view them in a searchable list and manage a simulated 100 MB quota with live statistics. The cognitive module provides twelve short games across two tracks — Cognitive Aptitude and Game-Based Assessment — with immediate scoring and a performance dashboard. All data stays in the browser: file metadata and game results are persisted with localStorage, and no server or database is required.

🎯 Objectives

  • Build a clean cloud-style dashboard with a responsive layout.
  • Allow selection of multiple local files and validate a 100 MB quota.
  • Display file count, used storage, free storage and a progress bar.
  • Support filename search and removal of file entries.
  • Organise twelve mini-games into two clearly identified tracks.
  • Show scores and a performance index immediately after play.

🚀 Future scope

  • Connect the dashboard to a Node.js or Python backend.
  • Store real files in cloud object storage such as Amazon S3.
  • Add user accounts, authentication and access control.
  • Keep scores and files in a cloud database for cross-device access.
  • Add preview, download, sharing, encryption and audit logs.
  • Introduce leaderboards and adaptive difficulty for the games.

A note on the implementation

The submitted report documents the Cloud-Based Cognitive Games build (React 19, TypeScript, Vite, deployed on Vercel). This repository implements the same experience as a dependency-free static site so it can be opened directly, hosted on GitHub Pages, and reviewed without installing anything. The accompanying presentation documents the cloud storage prototype, which is also included here as the CloudBox storage module.
